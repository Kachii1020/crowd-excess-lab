# Pre-hackathon baseline

The repository state at commit `968bf0b66373154089bb0665653e735707904ca6` is preserved by
the `pre-hackathon-research` tag. That baseline contains the Korean-equity feasibility study,
40-event OpenDART/NAVER research snapshot, read-only FastAPI projection, English research UI,
CI, and Vercel preview configuration.

The Alpaca options agent, OpenAI evidence assessment, deterministic paper-trading risk boundary,
Supabase audit store, and agent-specific interface are a separately documented milestone under
`specs/005-crowd-excess-options-agent/`.

This history is intentionally retained so judges can distinguish prior research and interface
work from the hackathon agent milestone. No existing result is represented as live trading or
validated profitability.
